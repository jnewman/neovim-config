# incline.nvim

## Purpose

A small floating filename label anchored to each window, following focus as
you move between splits — a per-window winbar. Shows the basename plus a
`[+]` marker when the buffer is modified.

## Keybindings

None — purely visual, no user-facing commands.

## Config Notes

Default config (`require("incline").setup()` with no options): text-only
label, no icons, no other customization.
