# tokyonight-nvim

## Purpose

A deep blue/purple colorscheme inspired by Tokyo at night. The night half of the
**`cyber`** pair; [fairyfloss](fairyfloss.md) is the day half.

## Keybindings

See [theme pairs](../themes.md) — `<leader>tt` cycles pairs, not individual
themes.

## Config Notes

- `style = "moon"` — mirrors the Ghostty "TokyoNight Moon" theme (`#222436`);
  other options: `"night"`, `"storm"`, `"day"`
- Applied by name as `tokyonight-moon`
- `terminal_colors = true` — sets terminal ANSI colors to match the theme
