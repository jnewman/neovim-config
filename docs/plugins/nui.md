# nui.nvim

## Purpose

UI component library (popups, splits, layouts). Required as a dependency by
[noice.nvim](noice.md) and [hardtime.nvim](hardtime.md) (its report popup).

## Keybindings

None — library dependency, no direct user-facing features.

## Config Notes

No configuration — installed purely to satisfy noice.nvim and hardtime.nvim
dependencies.
