# fidget.nvim

## Purpose

Shows LSP progress (indexing, diagnostics, etc.) as small notifications in
the bottom-right corner.

## Keybindings

None.

## Config Notes

Default config (`require("fidget").setup()` with no options). noice.nvim's
own LSP progress view is disabled (see [noice.md](noice.md)) so fidget is the
only thing showing it.
